🌳 What is ThoughtTree?
ThoughtTree is a fast, distraction-free 60 FPS mind mapping app. Your maps auto-save locally on your device, export cleanly to JSON, Markdown (.md), FreeMind (.mm), or PNG, and sync live across your devices via conflict-free CRDTs.
💻 How to Install on Laptop (Windows, Mac, Linux, Chromebook)
1. Open ThoughtTree from your hosted https:// link (e.g. GitHub Pages) in Chrome, Edge, or Brave.
2. Click 📲 Install ThoughtTree App in the top-left ☰ Menu (or click the Install icon in the right side of your browser's address bar).
3. ThoughtTree will launch in its own standalone window and pin to your Desktop / Taskbar / Dock—working 100% offline!
📱 How to Install on Android Phone / Tablet
1. Open your GitHub Pages https:// URL in Chrome for Android.
2. Tap ☰ Menu → 📲 Install ThoughtTree App, or tap Chrome's three-dot menu (⋮) → Install app / Add to Home screen.
3. ThoughtTree installs into your Android app drawer with its custom tree icon and full-screen touch dock.
🍎 How to Install on iPhone / iPad (iOS / iPadOS)
1. Open your GitHub Pages https:// URL in Safari.
2. Tap the Share button (square with upward arrow) at the bottom of Safari and tap Add to Home Screen.
⚡ Quick-Start Controls
• Desktop Keyboard: Press Tab for a Child node, Enter for a Sibling node, F2 (or just start typing) to edit text, Space to fold/expand, L to draw a dashed cross-link, and N to add notes/links. Hover over the top-right ? icon anytime for the full cheat-sheet.
• Mobile Touch: Tap any node and use the bottom thumb-zone dock (+ Child, + Sibling, Edit, Note, Link, Fold, Del), double-tap a node to edit text, or long-press any node for the full 12-action menu.
